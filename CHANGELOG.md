# Changelog

## 1.0.1
- Updated for Bannerlord v1.5.7. The reinforcement rules were checked against the 1.5.7 game code; custom battles now use waves like the campaign, and the tracker follows that.
- Mod Configuration Menu is now optional: without it the mod runs on its default settings.
- The launcher no longer warns that the dependencies don't match: each one now states the version it needs.

## 1.0.0
- Panels beside the battle scoreboard (Tab) with each side's total troops including reinforcements still to come, the next wave's size and the casualties it still needs.
- Works in field battles, sieges and hideout assaults (classic and stealth).
- Optional alerts when a side is partway to its next wave and when reinforcements arrive.
- Mod Configuration Menu options for the panels, alerts and debug messages.
